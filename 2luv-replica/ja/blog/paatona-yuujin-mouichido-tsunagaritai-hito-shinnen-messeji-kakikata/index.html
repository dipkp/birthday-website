気持ちがちゃんと伝わる新年メッセージを書くには

0時を回る直前、送る文面だけがなかなか決まらない。あの感じ、わりと多くの人が経験しています。新年には、その年ごとの感情の天気があります。あたたかな灯りや花火、年越しの瞬間に隣にいてほしい人を思い浮かべる人もいれば、友人たちと台所に立って、にぎやかな声と料理の匂いに包まれる時間を大事にする人もいる。そして中には、年の変わり目だからこそ、言えなかったことを伝えたい、ぎくしゃくした関係を少しでもほどきたい、正直にやり直したいと思う人もいます。だからこそ、意味のあるShinnen Messeejiには価値があります。季節のあいさつで終わらせるには、もったいない。相手が自分にとってどんな存在か、この先どんな関係を築きたいのかを、きちんと言葉にできる機会だからです。

このテーマには、感情の幅があります。ひとつは恋の高揚感。ひとつは、いっしょにごはんを作るような日常の親しさ。そしてもうひとつは、少し勇気のいる会話です。どれも2luvの新年メッセージに自然につながります。新年は、お祝いするだけの日ではありません。振り返る日でもあるし、感謝を伝える日でもある。途切れかけた関係に、もう一度手を伸ばすタイミングでもあります。

写真が教えてくれる、新年の恋愛・友情・仲直りのかたち

線香花火の写真には、年越しらしいロマンチックな空気があります。近さ、ぬくもり、新しい時間へ一緒に進んでいく感じ。ただ、線香花火はずっとは続きません。そこが大事です。気持ちは、その場でちゃんとすくい上げないと、案外するっと過ぎてしまう。パートナーに送るShinnen Messeejiは、無難すぎると響きません。ふたりだけがわかる記憶や、相手の好きなところ、この先のふたりにしか当てはまらない願いを入れたほうがいい。私はそのほうが、ずっと誠実だと思います。

台所の場面は、また別の良さを見せてくれます。強い関係は、大げさな演出より、繰り返される小さな習慣でできていることが多いものです。一緒に料理すること、失敗して笑うこと、さっと手伝うこと、ちゃんとそこにいること。友情も、長く続く恋愛も、そういう普通の日の積み重ねで深まっていきます。いい新年メッセージは、一年のハイライトだけでなく、関係を安心できるものにしてくれた日常の一場面まで拾えていると強いです。

たとえば、鍋のふたを開けた瞬間に湯気でメガネが曇って、相手が笑いながら菜箸を渡してくれた夜。そういう場面は、他人から見れば何でもない。でも、当人同士には妙に残ります。メッセージに必要なのは、きれいな言い回しより、そういう具体です。

最後の写真は、空気が変わります。張りつめた感じ、真剣な視線、感情を隠しきれない場面。これも新年らしい一面です。年が変わると、人は自然に振り返ります。会えていない人のこと、こじれた原因、もう一度向き合う価値があるかどうか。そんなときのShinnen Messeejiは、恋愛の言葉にも、感謝の言葉にも、関係修復のきっかけにもなります。ときには「あけましておめでとう」より、「今年はあなたに対してもっとちゃんと向き合いたい」や「まだ大切に思っている。正直に話せたらうれしい」のほうが、ずっと意味があります。

意味のあるメッセージは、関係性の研究ともちゃんとつながっている

いい新年メッセージが機能するのは、同時に三つのことをしているからです。相手に「ちゃんと見てもらえている」と感じさせること。感情のつながりを確かめること。そして、この先を一緒に考える方向感覚をつくること。これはきれいごとではなく、関係性の心理学でもかなり一貫して支持されているポイントです。

幸せなカップルには、互いに相手へ向き合う習慣がある。

John Gottman『The Gottman Institute / Gottmanの関係性研究』より

ここで参考になるのが、ジョン・ゴットマンの研究です。新年メッセージは、相手に向けた“つながりの呼びかけ”でもあります。文を送るのは、ただカレンダーが変わったことを知らせる行為ではありません。あなたのほうを向いています、これからも気持ちの距離を保ちたいです、と示す行為です。だから短い一文でも、個人的で誠実なら、思った以上に深く残ります。

弱さを見せることは、愛、居場所、喜び、勇気、共感、創造性が生まれる場所だ。

Brené Brown『Daring Greatly』より

ブレネー・ブラウンの言葉は、なぜ“うまい文章”より“本音のある文章”が勝つのかを説明してくれます。たとえば「今年もよろしくお願いします」だけで済ませるより、「あなたが根気よく付き合ってくれたおかげで、この一年はずいぶん救われた」や「しんどい時期もあったけれど、それでも私はふたりのことを信じたい」と書くほうが伝わる。少し照れくさいくらいで、ちょうどいい。弱さや本音がある文章には、感情の信頼性があります。

愛は行為であって、単なる感情ではない。

bell hooks『All About Love: New Visions』より

bell hooksの考え方は、とても実用的です。愛は感じるものでもあるけれど、それ以上に“すること”でもある。そう考えると、新年メッセージは、感傷的なひとこと以上のものになります。いたわり、敬意、修復、感謝、約束。そうした行動の一部になれる。これは、恋人に送るときだけでなく、親しい友人や、信頼を取り戻したい相手に書くときにも重要です。

愛こそが、人間存在の問題に対する、唯一健全で満足のいく答えである。

Erich Fromm『愛するということ』より

エーリッヒ・フロムの古典的な視点は、意味のある関係が“続けていく実践”だと思い出させてくれます。新年は、その実践をあらためて確かめるのにちょうどいい節目です。恋愛でも、友情でも、関係修復でも、メッセージは好意だけでなく、これからどうしたいかという意志が入るとぐっと強くなります。

心に残る新年メッセージを作る4つのパーツ

  1. まずは、ふたりのあいだで共有されている事実から始める。一緒に過ごした一年のこと、今も残っている気持ち、具体的な思い出を入れると、ありきたりな文になりません。
  2. 感謝している点をはっきり書く。やさしさ、ユーモア、誠実さ、忍耐強さ、必要なときにそばにいてくれたことなど、できるだけ具体的に。
  3. 今の正直な気持ちを言う。愛情、感謝、希望、後悔、尊敬、もう一度つながりたい気持ち。ここを濁さないほうが、文章は生きます。
  4. 来年に向けた意志で締める。願いでも、約束でも、誘いでもいい。先の時間を一緒に見ていることが伝われば十分です。

この型は、どんな関係にも使えます。恋人なら、もっと親密で愛情のある言い方になるでしょう。親友なら、少しくだけていても深い感謝が出せます。こじれた関係なら、まず自分の責任を認めたうえで、無理のない希望を添えるのが自然です。完璧な文を目指さなくていい。必要なのは、感情の事実です。

パートナーに送る新年メッセージ、こう書くとちゃんと届く

恋人やパートナーにそのまま使いやすい、新年メッセージの文例です。

  • あけましておめでとう。去年は忘れたくない小さな瞬間がたくさんあったけれど、そのどれもで一番うれしかったのは、あなたと一緒にいられたことでした。安心できる場所でいてくれて、笑顔をくれて、今も変わらず心から大切にしたいと思える人でいてくれてありがとう。今年もまた、ふたりの思い出を増やしていけるのが楽しみです。
  • 新しい年の始まりに、まず伝えたいのは、あなたへの深い感謝です。あなたの愛情のおかげで、つらい日は少しやわらぎ、いい日はもっと明るくなりました。今年が、もっとたくさん笑えて、もっと穏やかで、もっとお互いを大切にできる一年になりますように。
  • 年が変わっても、この気持ちは変わらない。私の心は今もあなたに向いています。この一年、いろいろなことがあっても隣にいてくれてありがとう。あなたといるときの自分が好きです。これからも一緒に築いていくものを、楽しみにしています。
  • 今夜に希望を感じるのは、あなたが私の人生にいるからです。今年どんなことがあっても、正直さとやさしさを忘れず、あなたを大切にしながら向き合っていきたい。私の未来を楽しみなものにしてくれるあなたへ、あけましておめでとう。

友人に送る新年メッセージは、気軽でも薄くしない

友人や、家族のように大切な存在に向けた、すぐ使える新年メッセージの文例です。

  • あけましておめでとう！ 去年の中で、本当に良かったことのひとつがあなたの存在でした。笑い合った時間も、ちゃんと話を聞いてくれた時間も、私が思っている以上に支えになっていました。今年があなたにとって、喜びと健康と、あなたが周りにくれるようなあたたかさに満ちた一年になりますように。
  • あなたがいてくれたから、この一年は確実にいいものになりました。顔を出してくれて、話を聞いてくれて、一緒に笑ってくれて、何でもない日をちょっと特別にしてくれてありがとう。あなたとの友情に心から感謝しています。今年もまた、一緒にいい思い出を増やせたらうれしいです。
  • 今年が、おいしいものと、いい人たちと、あなたにふさわしい穏やかさに満ちた一年になりますように。この一年、どんな時期の私にもちゃんと向き合ってくれる“本物の友だち”でいてくれてありがとう。応援しているし、心から感謝しています。
  • あけましておめでとう。あなたは、友だちというより帰れる場所みたいな人です。今年を少し軽く、少し明るくしてくれた大小いろいろな瞬間をありがとう。これからの一年が、うれしい形であなたをたくさん驚かせてくれますように。

仲直りや関係の立て直しに使う新年メッセージの文例

正直に伝えたいとき、謝りたいとき、途切れた会話をそっと開き直したいときのための、新年メッセージ例です。

  • 新しい年が始まって、私たちのことや、もっとちゃんと伝えるべきだったことを考えていました。去年は簡単な一年ではなかったし、その中で私自身が傷つけてしまった部分があったことを後悔しています。今も大切に思っています。もし気持ちに余裕があれば、今年はもう少し正直に、そして敬意を持って向き合えたらうれしいです。
  • あけましておめでとう。何もかもが平気だったように装いたくはないし、あなたが大切な存在だということを伝えないまま新しい年を始めたくもありませんでした。私たちの距離を広げてしまった自分の部分について、ごめんなさい。タイミングが合うときに、話せたらと思っています。
  • 年の始まりは、解決できていないことを自然と振り返らせます。そして今、あなたのことを思っています。一緒にいた時間の良さに感謝していますし、その間に生まれてしまった傷つきには申し訳なく思っています。もし話す余地があるなら、丁寧に前へ進む機会をもらえたらうれしいです。
  • メッセージひとつで全部が解決するとは思っていません。でも、今年の始まりを誠実さから始めたかった。あなたは私にとって本当に大きな存在でしたし、沈黙やすれ違いを後悔しています。この新年が穏やかなものになりますように。もしよければ、無理のない形で、もう一度正直に話せたらと思っています。

2luvの新年ギフトを“ちゃんと自分の言葉”にするコツ

  • 具体的な思い出をひとつ入れる。線香花火を見た夜、一緒に作ったごはん、つらい日に電話を切らずにいてくれたこと、関係が変わるきっかけになった会話など。
  • 五感の情報を少し足す。あたたかい灯り、台所の音楽、冬の空気、年越しの笑い声、つないだ手の感触。
  • 尊敬しているところをひとつ言葉にする。落ち着き、忍耐強さ、誠実さ、ユーモア、気前のよさ、信頼できるところなど。
  • 来年への願いは、人間らしい言い方で書く。ゆっくりした朝が増えること、もっとちゃんと話せること、距離が縮まること、少し勇気を持てること、一緒に笑う時間が増えること。
  • メッセージに、2luv上のデジタルの記念を添える。写真の思い出、個人的なメモ、その一年の感情をたどれるようなタイムラインなどを組み合わせると、ぐっとその人のための贈り物になります。

デジタルギフトが記憶に残るかどうかは、形式では決まりません。感情の解像度で決まります。いい2luvの新年ギフトは、「これは自分のために作ってくれたんだ」と相手がすぐわかるものです。ふたりの実際の歴史がメッセージに入っていれば、お祝いが終わったあとにも、また見返したくなるものになります。

新年メッセージは、結局“関係のメッセージ”だ

新年のいいところは、いろいろな種類の愛情をいっぺんに抱えられることです。線香花火みたいに恋愛的でもいいし、台所の時間みたいに仲間とのぬくもりでもいい。あるいは、気まずさを越えて向き合う勇気でもいい。形は違っても、下に流れているメッセージは同じです。あなたは私にとって大事な人だと、この瞬間を黙ったまま通り過ぎたくない。

この季節に2luvでデジタルギフトを作るなら、いちばんうまい言い回しを狙わなくていいです。いちばん本当の言葉を選んでください。意味のある新年メッセージは、具体的で、少し無防備で、ちゃんと意志があるものです。過去を大切にし、今を正直に語り、そのうえで未来にそっと手を伸ばしている。関係によっては、それが新しい始まりに本当に必要なことだったりします。
