Ayuda para crear tu web de cumpleaños

Tu regalo de cumpleaños, paso a paso

¿Cómo será el regalo de cumpleaños?

Birthday Party empieza con un pastel 3D que abre tu carta, fotos, música y sorpresas. Felicita a un amigo, familiar o pareja y personaliza los momentos que quieras incluir.

¿Cómo hago personales mis felicitaciones?

Empieza con el nombre de quien cumple años. Cuenta algo que admiras, recuerda un momento compartido y añade un deseo para el próximo año. Elige fotos que reconozca y una canción que le represente; completa los datos del cumpleaños cuando estén disponibles.

¿Cómo añado o cambio una foto?

Usa Añadir fotos para elegir varias imágenes de la biblioteca o subirlas. Para cambiar una, pulsa su miniatura y elige una sola imagen; las otras fotos, su pie y fecha se conservan. Confirma el cambio o cancela para mantener la original.

¿Puedo empezar con un ejemplo?

Abre Ver un ejemplo para explorar el diseño. Usar este ejemplo rellena el editor con contenido de muestra; si tienes un borrador, puedes conservarlo o confirmar su sustitución. Deshacer ejemplo lo restaura mientras sigues en la página. Cambia los nombres, textos y fotos antes de enviarlo.

¿Qué debo revisar en la vista previa?

Revisa el nombre, las felicitaciones, el encuadre y la canción. Abre cada momento incluido y comprueba las fechas o cuentas atrás que hayas añadido. El ejemplo usa contenido de muestra; tu propia vista previa muestra el regalo que estás creando.

¿Cómo envío el regalo terminado?

Completa los pasos de creación y sigue las opciones que aparecen para dejar el regalo listo para compartir. Cuando estén disponibles las opciones de compartir, envía el enlace por mensaje o email, o usa el código QR en una tarjeta impresa. Guarda el enlace y los datos de acceso mostrados. Si configuraste una contraseña, envíala al destinatario por separado.
