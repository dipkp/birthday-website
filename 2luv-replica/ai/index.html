Stuck on the words? Ask the letter model.

Three opening lines for a birthday letter, generated on your machine through the FreeLLMAPI gateway. The request is encrypted: this page holds only a short-lived session key, and the API key itself never leaves the local service.

Transport: AES-256-GCM · key issued per session (15 min) · ciphertext + tag, HMAC-tagged envelope. Model call goes to 127.0.0.1:31415 from the service, never from the browser. If you see session_required, the service restarted — reload the page.
