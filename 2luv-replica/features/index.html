Reverse-engineering notes

The interactions, one by one

Every moving part of the original page, pulled out of its inline scripts and made runnable on its own — so you can see exactly how each one behaves without scrolling 12 000 pixels to find it. The mechanics are the origin's; only the chrome around them is new.

  • 6 interactions reproduced
  • 420 ms candle step interval
  • 60 days countdown window
Interaction 01

Hold to blow the candles

The headline feature. The birthday person presses and holds a button — the page steps down one lit wick every 420 ms, leaning each flame sideways while the wind is on, then swaps in a relight control and a “Wish made!” confirmation. The published copy is explicit that the breath is only ever detected on-device; the demo here keeps that contract by using the press itself as the signal rather than opening a microphone.

  • data-lv3-candles
  • data-lv3-blow
  • data-lv3-relight
  • data-lv3-candles-done
  • .lv3-wick[data-lit]
  • data-state="lit|out"
  • data-wind="on|off"
press and hold →

What the original does

Pointer events drive it, not a microphone. pointerdown takes pointer capture and starts the interval; pointerup, pointercancel and lostpointercapture all stop it, so a drag off the button can't leave the candles burning down on their own.

Keyboard and assistive tech get a different path: a single click blows all the candles out one by one, because a hold gesture isn't available. The origin also intercepts the trailing synthetic click after a pointer hold so it doesn't double-fire — that guard is reproduced here.

Interaction 02

Foil balloons that spell the age

A stepper clamps the age to 1–99 and rebuilds the balloon row from per-digit artwork: one balloon when the age is a single digit, two side by side otherwise. Each digit ships as a responsive <picture> with AVIF and WebP sources, so the row stays sharp on a phone.

  • data-lv3-age-root
  • data-age-step="±1"
  • data-lv3-balloons
  • data-age-value
  • balloonSources[digit]
30

The origin builds this DOM in JavaScript rather than shipping it in the HTML, which is why the balloon srcset strings live inside an inline script — a detail that breaks naive asset rewriting.

Sizing

The origin's sizes attribute: (max-width: 900px) 75px, (max-width: 1280px) 12vw, 142px — a fixed 75 px on small screens, then a fluid 12 vw, then capped.

Intrinsic dimensions are declared as 351×523 so the row reserves its height before the artwork loads and nothing jumps.

Interaction 03

Countdown to the party

Pick a birthday and the page reports the days remaining. The origin defaults the field to a sample offset so the control is never empty, floors the minimum at today, and rolls a date that has already passed into next year — so a birthday entered as 3 March always means the next 3 March.

  • data-lv3-countdown
  • data-lv3-countdown-date
  • data-lv3-countdown-number
  • data-lv3-countdown-result
  • data-today="true|"
—days to go

Zero is a special state, not “0 days to go”: the page flips to a today message and sets data-today="true" so the stylesheet can celebrate it.

Where the window comes from

The landing copy says the countdown appears during the 60 days before the birthday, and the field is pre-seeded today + sample so a visitor sees a live number immediately rather than an empty box.

Days are counted on UTC-normalised dates, so a daylight-saving shift mid-window can't knock the total off by one.

Interaction 04

Confetti

Pure CSS. Sixteen absolutely positioned spans fall on independent durations and delays, drifting sideways and spinning as they go; every third one renders as a circle instead of a rectangle. No canvas, no library.

  • .lv3-confetti i
  • --x --r --c --d --delay

Why it's cheap

Each piece is one custom-property-driven element, so the whole effect is a single keyframe animating transform only — compositor-friendly, and it costs one DOM node per confetto. Under prefers-reduced-motion the layer is removed outright rather than merely slowed.

Interaction 05

Message templates and copy-to-clipboard

Three pre-written birthday messages, each a starting point the sender is meant to edit. Copying reads the text out of the rendered node, falls back to a hidden textarea on browsers without the async clipboard API, and confirms inline for a couple of seconds.

  • data-lv3-messages
  • data-lv3-template
  • data-lv3-message-text
  • data-lv3-copy
Interaction 06

Three-state theme

Not a two-way light/dark switch — the cycle is system → light → dark → system, persisted to localStorage under theme. “System” is a real state that follows the OS live via matchMedia, rather than a snapshot taken once at load.

  • data-theme
  • data-resolved-theme
  • html.dark
  • localStorage.theme

How the two implementations differ

The header bundle owns the real toggle; a small inline fallback in the page footer applies the same rules if that bundle hasn't loaded yet, so the theme never flashes. Both write the same key and both broadcast a change event, which is why toggling from either place stays in sync.
