製作禮物的說明

個人化、預覽與分享

應該選擇哪種設計？

浪漫留言可以選擇情書，生日祝福可以選擇生日信。電影式設計會把回憶放進主題場景，上方列出了目前可用的選項。開始前可以開啟範例了解設計。已鎖定的設計會保留開放提示，尚未開放時，不能從該卡片開始建立。

如何加入自己的心意？

在信件編輯器中，先填寫收禮人的名字；若提供署名選項，再加入自己的簽名。在「回憶」中用自己的話寫留言、選擇照片，並貼上支援的歌曲連結。不同設計可能還有其他可自訂的細節。選擇你想讓對方看到的照片，檢查畫面裁切，並在繼續之前校對文字。

預覽時需要檢查什麼？

完成前，使用預覽檢查留言、照片裁切和音樂。在手機上，預覽按鈕會在表單之外開啟禮物。範例中的名字、照片與文字都是示範內容，用來展示設計，並非你的個人內容。關閉範例即可回到表單；要檢查自己填寫的內容，請開啟自己的預覽。 「使用此範例」會用示範內容填入編輯器。如果草稿已有內容，需要先確認替換；只要留在目前頁面，「復原範例」即可恢復草稿。

如何傳送完成的禮物？

完成建立步驟，並按照頁面顯示的選項準備分享禮物。分享選項可用後，你可以透過訊息或電子郵件傳送連結，也可以把 QR Code 用於印刷卡片。請保留頁面顯示的連結與存取資料。如果你設定了密碼，請另外把密碼傳送給收禮人。
